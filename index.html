Any Python snippet works — loops, recursion, sorting, linked lists...
Built with plain HTML / CSS / JS — no server, no backend, nothing to install.
Fonts: Kalam, Nunito, JetBrains Mono (Google Fonts).
The core engine is Pyodide — real CPython compiled to WebAssembly, run entirely in your browser — which actually executes your code to build the Story, Flowchart, "What's Used", and Interview Tips tabs from real values, not guesses.
Turning on the checkbox above loads Transformers.js (Hugging Face's in-browser ML library) with a small model to rephrase the wording more naturally. It's optional because it's a real multi-MB download — everything works accurately without it.
If neither can start (e.g. a sandboxed preview blocking WebAssembly), a free remote text API and a built-in offline analyzer step in as fallbacks — a badge on every tab always shows which source produced that result.
