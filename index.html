How This Program Works

Here is what happens behind the scenes when you submit your code.

  • Frontend UI: Built with pure HTML, CSS, and vanilla JavaScript.
  • Local Engine: A built-in regex pattern matcher that recognizes common algorithms (like Two Pointer, Stack, Linked Lists).
  • AI Engine (Gemini): Connects directly from your browser to Google's free Gemini API to read unfamiliar code and format it into a story object.
